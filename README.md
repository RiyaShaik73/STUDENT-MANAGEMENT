# Unified Learning Progress Web App

This project now has normal web pages and API endpoints.

## Page Flow

1. Home page: `/`
2. Signup page: `/signup`
3. Login page: `/login`
4. Dashboard page: `/dashboard`
5. Extra pages: `/profile`, `/analytics`, `/assignments`

## API Endpoints

These return JSON for API practice:

- `GET /api/students`
- `GET /api/progress/riya@example.com`
- `GET /api/dashboard`

## Run

```powershell
venv\Scripts\activate
python app.py
```

Open `http://127.0.0.1:5000`.
